# Cognitive games (Phase 3)

Five offline games. Results are stored in Dexie `gameResults` (`synced: false`). No FastAPI or MongoDB.

- `memory_cards`
- `object_recognition`
- `pattern_recognition`
- `daily_routine_recall`
- `attention`

Content is the bundled generic pack (emoji + i18n keys). Difficulty is a fixed default until Phase 5.
