# Caregiver & Healthcare Worker Dashboard

The Phase 9 dashboard transforms Smriti from a single-player game into a supervised care platform.

## Architecture

The dashboard is built using React and Recharts on the frontend, and FastAPI with PyMongo on the backend.
It operates under a strict role-based authorization model (see `ROLE_PERMISSIONS.md`).

## Dashboard Structure

### 1. Global Overview (`/caregiver/dashboard`)
Shows top-level metrics for all patients assigned to the caregiver:
- Total Patients
- Active Today
- Reminders Completed
- Total Alerts

### 2. Patient List (`/caregiver/patients`)
A table view listing all assigned patients. It provides a quick summary of:
- Last active timestamp
- Today's activity count
- Reminder status (e.g. 5/8 completed)
- Latest cognitive score
- Alert badges

### 3. Patient Profile (`/caregiver/patients/:id`)
A detailed view of a single patient.
- **Activity & Trends:** Line charts showing cognitive scores and reminder adherence over the last 30 days.
- **Games:** A breakdown of performance across all 5 cognitive games.
- **Reminders & Routine:** Adherence metrics.
- **Alerts:** Specific warnings generated by the Alert Engine.

## Medical Safety Disclaimer
The dashboard is strictly an observational tool. It does not provide medical diagnoses.
All UI text is carefully worded to be neutral (e.g., "Performance decreased compared with previous period" rather than "Cognitive decline detected"). Caregivers are reminded via a persistent disclaimer that the tool is for care coordination, not clinical diagnosis.
